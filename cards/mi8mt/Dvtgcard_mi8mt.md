# {u:ПРИЗНАКИ:}

- мигание кнопки-табло {yellow:ЦСО} желтого цвета;
- загоранием сигнального табло {lime:ОГР n,Тг ЛЕВ (ПРАВ) РАБОТАЕТ};
- возможным повышением температуры газов перед турбиной компрессора выше допустимой.

@chartreuse
# {u:ДЕЙСТВИЯ:}

Контроль за параметрами работы двигателя - усилить - {coral:КВС}, {yellow:Б/М}.
КВС и Б/М усилить контроль за параметрами работы двигателя, убедиться в исправности аппаратуры замера температуры газов. Если температура будет в допустимых пределах для данного режима, продолжить выполнение полета.

{yellow:В случае повышения температуры газов перед турбиной компрессора выше допустимой, двигатель - выключить - Б/М}, {coral:КВС}.
КВС дать команду Б/М выключить неисправный двигатель краном останова, выключить ЦСО.
Б/М по указанию КВС выключить двигатель краном останова.

{lime:Службе УВД о случившемся и принимаемых мерах - сообщить - 2/П}, {coral:КВС}.
КВС или по его команде 2/П сообщить службе УВД о случившемся и принимаемых мерах.

Если один из двигателей выключен, действовать, как при полете с одним неработающими двигателем - {coral:КВС}, {yellow:Б/М}, {lime:2/П}.
Всем членам экипажа, если один из двигателей выключен, действовать в соответствии с указаниями для полета с одним неработающим двигателем.
