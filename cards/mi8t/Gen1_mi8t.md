# {u:ПРИЗНАКИ:}

- загорается табло {red:ОТКАЗАЛ ЛЕВЫЙ (ПРАВЫЙ) ГЕНЕРАТОР};
- падение стрелки амперметра отказавшего генератора до нуля.
При установке переключателя ГЕНЕРАТ. ШИНА на отказавший генератор стрелка вольтметра будет на нуле.

При отказе одного из генераторов второй работающий генератор полностью обеспечивает питание всех потребителей электроэнергии вертолета, и полет может продолжаться без каких-либо ограничений.
