# {u:ПРИЗНАКИ:}

- стрелка амперметра отказавшего ВУ устанавливается на нуль.

@chartreuse
# {u:ДЕЙСТВИЯ:}

Установить выключатель отказавшего ВУ ВЫПРЯМИТЕЛИ 1 (2, 3) на щитке ПОСТОЯННЫЙ ТОК в положение {chartreuse:ВЫКЛ}.
{chartreuse:Продолжить выполнение задания}.

{orange:Примечание.} При отказе одного из выпрямителей два работающих выпрямителя полностью обеспечивают питание всех потребителей электроэнергии вертолета, необходимых для продолжения полета.
